# 背景改多色（mesh gradient）

> 2026-10-31 追加。用户第三轮反馈："背景的颜色很单调"。

## 上一版为什么还是白

上一轮我只把"页面内容"改成了多色（状态标签、数字、图表），但**背景没动**：

1. 背景只在最上面 200px 有一条极浅的单色带，往下全白
2. 卡片是 100% 不透明白色——它把背景**完全挡住**了

所以整页看起来依然是白纸。这两个问题必须一起解决。

## 这一版做了什么

### 1. 背景改成"多色柔光"（mesh gradient）

不是色块拼接，是 5 个色相的径向渐变互相叠加，叠出来的是一种"雾面极光"效果：

| 位置 | 颜色 | 透明度 |
|---|---|---|
| 左上 | 靛蓝 `#4F46E5` | 34% |
| 右上 | 青 `#0891B2` | 30% |
| 左中 | 紫 `#7C3AED` | 28% |
| 右下 | 琥珀 `#D97706` | 22% |
| 中下 | 绿 `#059669` | 18% |

透明度都压得很低，叠出来的背景最深处在 `#EFE9FC` 级别，正文 `#111827` 对其对比度 > 12:1。

### 2. 卡片改半透明白 + 背景模糊（frosted glass）

```css
background: rgba(255, 255, 255, 0.7);
backdrop-filter: saturate(150%) blur(16px);
```

让底色能透上来。文字仍然压在 70% 白薄膜上，对比度不掉。
关键数字卡（汇总、出勤率、身份卡）用 80% 不透明度，保证数字最清晰。

### 3. 顶栏 / tabbar 同样半透明

让颜色在整页连续不断，而不是"上半段有色、下半段白"。

## 踩到的坑（重要）

**第一次改完只看到顶部一段有颜色，往下又是白。**

原因：我把柔光写在 `.shell` 上，并用了 `background-attachment: fixed`。
`fixed` 在滚动容器里只会"对准视口一次"，内容一滚就露白；
而 `.shell` 的高度是随内容拉伸的，渐变也只铺了顶部一段。

**修法**：把渐变换到 `body` 上 + `background-attachment: fixed`，
`.shell` 设为 `background: transparent`。这样柔光固定铺满整个视口，
页面无论滚到哪里，背景都是那层光。

## 两个浓度可选

| 参数 | 描述 |
|---|---|
| `?bg=7`（**默认**） | 更浓：靛蓝 34%、青 30%、紫 28%、琥珀 22%、绿 18% |
| `?bg=6` | 更淡：靛蓝 20%、青 18%、紫 16%、琥珀 12%、绿 10% |
| `?bg=0` | 回到纯白（旧版） |

线上对比：
- https://jimgreen1565-droid.github.io/punch-clock/
- https://jimgreen1565-droid.github.io/punch-clock/?bg=6
- https://jimgreen1565-droid.github.io/punch-clock/?bg=0

## 深色模式

`prefers-color-scheme: dark` 下自动切换：背景 `#0f1115`，
色斑透明度提高（靛蓝 28%、青 18%、紫 22%、琥珀 14%、绿 12%），
卡片变 `rgba(23,26,33,0.72)`。多色在深底上会更鲜艳。
