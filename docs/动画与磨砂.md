# 动画、毛玻璃与磨砂颗粒（实测结论）

> 2026-10-31 追加。用户要求："加动画，毛玻璃可以用在这吗"

## 一、毛玻璃能不能用？能，但先说清楚它在这里的边界

**毛玻璃（`backdrop-filter`）的本质**：把身后的东西模糊掉，再加一层薄膜。
它成立的前提是**身后必须有内容可模糊**。

| 适合用 | 为什么 |
|---|---|
| 顶栏 / 底栏 | 身后是滚动经过的列表内容，滚动时能看出"内容在玻璃下滑过" |
| 弹层 / 底部抽屉 | 身后是页面，模糊后主次分明 |
| 浮在**有细节**背景上的卡片 | 身后若有图片/文字/纹理，模糊才有意义 |

| 不适合用 | 为什么 |
|---|---|
| 平滑渐变背景上的卡片 | **模糊平滑的东西等于没模糊**（本项目的实测结果） |
| 白底上的白卡片 | 身后没有色彩可模糊，付出性能但看不出 |
| 密集列表每一项 | 31 个元素各自 `backdrop-filter` 会掉帧 |

### 实测证据：大面积 backdrop-filter 在这个画布上收益接近零

同一位置、开/关 blur、同一帧截图对比：

| 指标 | 开 blur | 关 blur | 差异 |
|---|---|---|---|
| 相邻像素差（局部对比度） | 3.024 | 3.077 | **仅 1.7%** |

肉眼看两张截图（`docs/glass-compare-on.png` / `-off.png`）几乎完全一致。

**原因**：背景是极平滑的径向渐变，模糊它没有任何视觉变化。
毛玻璃的价值来自"身后有高频细节"，而这个设计的背景全是**低频**的。

### 所以最终方案：分开处理

1. **毛玻璃只用三处**：顶栏、底栏、弹层。它们身后有"滚动经过的内容"，这是真实收益。
2. **卡片的"质感"改用噪点**（`webapp/frost.css`）：SVG `feTurbulence` 生成的极细
   磨砂颗粒，叠在白色上。它不依赖背景，任何底色下都能看出"这是一块磨砂玻璃"。
3. **列表项完全不用 backdrop-filter**，只用半透明白 + 轻噪点，性能代价接近 0。

> 这是一个"用户提的方案局部不成立、但意图成立"的典型情形：
> 想要的是质感，而不是某个具体 CSS 特性。认识到瓶颈在哪之后换工具达成同样的目的。

## 二、动画：极光缓慢流动

### 实现

4 个模糊色球（靛蓝/青/紫/琥珀），各自沿不同轨迹缓慢移动：

| 色球 | 周期 | 位移轨迹 |
|---|---|---|
| 靛蓝 | 13s | 向右下漂移，尺寸微涨 |
| 青 | 17s | 向左下漂移 |
| 紫 | 19s | 向右上漂移 |
| 琥珀 | 15s | 向左上漂移 |

**周期刻意取 13/17/19/15（互不整除）**，这样视觉上不会形成可预测的循环感。
**幅度 ±20~32vmax**，3 秒就能看出明显位移（实测 3 秒位移 115px）。

### 性能约束（严格执行）

1. 只对 `transform` / `opacity` 动画，不碰 `width/height/top/left`（避免重排）
2. 色球 `pointer-events: none`，不拦截点击
3. `will-change: transform` 提前提升图层
4. `prefers-reduced-motion: reduce` 时全部静止

实测帧率：**242 fps**（60 帧平均间隔 4.13ms，最差 4.3ms），动画开销可忽略。

### 打卡按钮的呼吸光晕

按钮外圈加一层 `pulseGlow`，2.6 秒一个循环，`scale(1) → scale(1.22)` 同时
`opacity 0.55 → 0.15`。作用：让"现在是可打卡状态"这件事在视觉上是活的。

## 三、顺手修掉的真 bug：时钟不走了

对比两帧截图时发现**时钟完全没变**（10:42:56 → 10:42:56，间隔 3 秒）。

原因：`tickClock()` 只在 `renderIndex()` 末尾调用一次，页面停留期间没有 `setInterval`。
所以时钟是死的，只在每 10 秒重渲染那一瞬间跳一下。

修法：拆成 `startClock()`（`setInterval` 每秒 tick + 10 秒重算汇总）与
`stopClock()`（切页时清掉两个定时器，避免叠加多个 interval）。

验证：`10:47:08 → 10:47:11`，切页后 `10:47:13 → 10:47:15`，正常。

## 四、可切换入口

| 参数 | 效果 |
|---|---|
| **默认**（= `?bg=8`） | 动画极光 + 磨砂卡片 |
| `?bg=9` | 动画极光更浓 + 磨砂更重 |
| `?bg=7` | 静态多色柔光（无动画，最省电） |
| `?bg=0` | 纯白 |

线上：
- https://jimgreen1565-droid.github.io/punch-clock/
- https://jimgreen1565-droid.github.io/punch-clock/?bg=7（要省电就用这个）

## 五、性能与耗电提醒（如实说明）

动画会让 GPU 持续工作。实测帧率 242fps 说明**不会掉帧**，但**会略微增加耗电**——
打卡 App 一天开 4-6 次、每次 10 秒，这点耗电可以忽略；但如果用户把页面挂在后台
长时间不关，建议提供 `?bg=7` 的静态版本。

`prefers-reduced-motion` 已尊重系统设置：开了「减少动态效果」的用户会自动看到静态版。
